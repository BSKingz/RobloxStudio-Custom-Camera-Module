# Custom Scriptable Camera Module
**Different Camera Modes, Effects, Configuration To Customize For Your Needs!**

**Beta Release**
- Version = "0.1.0-beta", - Beta Release ( Major - Minor -Patch )

## Camera Modes
- **OTS (Over The Shoulder)** - Third-person shoulder camera positioning 
- **OTS Shoulder Switching** - Dynamic left/right shoulder transitions
- **First Person** - Immersive first-person perspective
- **Third Person** - Traditional third-person following camera
- **Orbital** - 360-degree camera rotation around subject
- **Fixed** - Static camera positioning
- **Cinematic** - Smooth camera movements for cutscenes

## Camera Effects
- **Camera Shake** - Impact/explosion shake effects
- **Smooth Interpolation** - Fluid camera transitions
- **FOV Adjustment** - Dynamic field of view changes
- **Zoom Controls** - In/out zoom functionality
- **Collision Detection** - Wall/obstacle avoidance
- **Look Smoothing** - Dampened camera rotation
- **Bobbing Effects** - Walking/running camera bob

## Advanced Features
- **Scriptable API** - Custom camera behavior scripting
- **State Management** - Camera mode switching system
- **Configuration System** - Adjustable camera parameters
- **Event Handling** - Camera state change callbacks
